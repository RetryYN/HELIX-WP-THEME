== Description ==

このテーマは WordPress 7.0 のフルサイト編集（FSE）要件を実測するための検証専用フィクスチャです。

**目的**
- WP7.0 が必須とする最小要件の確認
- Theme Check プラグインが何を指摘するかの実測
- theme.json v3 の動作確認

**本番テーマとして使用しないでください。**

== Installation ==

1. テーマディレクトリへアップロードする
2. WordPress 管理画面 > 外観 > テーマ から有効化する
3. Theme Check プラグインを実行して指摘項目を確認する

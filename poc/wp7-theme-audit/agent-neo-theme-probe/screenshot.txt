AGENT NEO Theme Probe — screenshot.png プレースホルダ

本番テーマでは以下の仕様の screenshot.png が必要。
  - サイズ: 1200 × 900 px（4:3 比率）
  - フォーマット: PNG または JPEG
  - 用途: wp-admin のテーマ一覧に表示されるサムネイル
  - wp.org への申請時は必須。Theme Check でも欠落を警告する

このフィクスチャでは screenshot.png を用意しない（wp.org 申請対象外のため）。
実測項目: Theme Check が screenshot.png 欠落を REQUIRED / WARNING のどちらで報告するか確認すること。

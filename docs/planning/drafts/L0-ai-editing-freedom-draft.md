# L0 改定ドラフト — コンセプト「AI と WP 編集の楽しさ」（構造自由・破壊域停止）

> 種別: L0 企画書改定案（旧 L0 企画書 L0-planning.md への差分。旧 L0 は削除済みで、本文書の「現行」列がその内容を保持する）。G0.5（企画↔L1 突合）を通るまで L1 以下へ波及させない。
> 作成日: 2026-08-28 / ステータス: Draft（PO 判断待ち）

## 1. 改定内容（案）

| 項目 | 現行 L0 | 改定案 |
|---|---|---|
| ビジョン | AI エージェントが第一級ユーザーとなる商用 FSE テーマ | 変更なし。副題として「AI と WP 編集の楽しさ」を追加 |
| 構造編集 | 個人版はテンプレ構造固定（REQ-F-016）。法人版は Blueprint slot で構造保護（REQ-F-037） | **構造自由**（パターン差し替え・ブロック編集・テンプレ変種）。ロックは最小限 |
| 値の編集 | プリセット中心（REQ-F-045 palette slug 参照） | 安全域（プリセット／尺度内の任意値）は自由・生値は警告、**破壊域は止める** |
| 位置づけ | 商用製品 | 運用知見・開発知見をためる場。実証済みパターンは別製品（GRAPHIX-NEO）へ一方向に取り込む |

破壊域の例: 余白・フォントサイズが尺度の最大/最小を超える、コントラスト比 AA 未満、幅 100% 超・負の余白・vh/vw 過大、任意 CSS の `!important`、位置固定 + 画面を覆う高さ。境界値は PoC で実物を崩して決める（要求段階で確定）。

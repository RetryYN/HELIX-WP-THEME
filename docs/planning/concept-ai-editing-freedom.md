## 1. 狙う体験

パターンを差し替え、スタイル案を切り替え、AI に「このセクションを 3 列にして」と頼む。壊れない範囲で何でも試せる。
本テーマの優位は「構造まで GUI/JSON で自由に編集でき、AI が同じ JSON で操作できる」こと（2026-08-27〜28 PoC）。

## 2. 設計方針

- **構造は自由**: パターン差し替え・ブロック編集・テンプレ変種。ロックは最小限。
- **値は 2 段**:
  - 安全域（プリセット、またはプリセット尺度の内側に収まる任意値）は自由。生値は警告のみ。
  - 破壊域（レイアウトや可読性を壊す値）は**止める**。baseline に関係なく 0 件。
    - 例: 余白・フォントサイズが尺度の最大/最小を超える、コントラスト比 AA 未満、幅 100% 超・負の余白・
      vh/vw の過大指定、任意 CSS の `!important`、位置固定 + 高さ過大（画面を覆う）。
    - 実装候補: theme.json の `custom*` 許可 + 保存時検査（G-S3 相当をエディタ側にも）+ レンダー側 CSS clamp（最終防衛線）。
      境界値は PoC で実物を崩して決める。
- **ゲート**: 既存の生値は「増やさない」（baseline、`config/design-consistency-baseline.json`）方式で段階的に減らす。
- **実験パターン**: どんどん入れる。カテゴリ `agent-neo-shared` / `agent-neo-lab` で分ける。

# 全要求のカタログ再現・追調査・品質改善

状態: 実行中。起点: 要求整理 PR #173、131要求・282 AC、試作03段13。

## POの目的

全要求をカタログで再現し、リサーチの取りこぼしを再確認して要求化する。取捨選択が十分容易になるまでカタログを整理し、現状を超えるデザイン品質を試す。必要な実在サイトの追調査も行う。既存の未検証を完了へ読み替えず、途中の使いやすさ改善だけでこの目的を完了にしない。

## 完了を示す証拠

1. 全要求・ACに、再現ページまたは操作デモ、設定と状態、再現手順、実測証跡、制約が対応する。表示以外の要求は操作・異常系・契約のデモと実行結果を持たせる。単なる説明カードや関連画像を再現完了と数えない。
2. 9系統を上限にせず、既存の種別台帳と実在例を再点検する。抜けを出所・目的・状態・採否・要求ID・検証対象へ接続する。調査件数だけで網羅としない。
3. 共通部品・各ページ面・状態を用途で探し、PC/SPを確認し、候補を比較し、採用候補・保留・除外と理由を保存・持ち出せる。これらの操作を実ブラウザで検証する。
4. 有料記事・インタビュー・BLPの独立した意味と管理、外部機能との接続・権限別表示・遷移を再現する。決済・会員等の業務処理をテーマへ持ち込まない。
5. デザイン改善は同じ内容・画面幅の変更前後で評価する。階層、組版、余白、画像、導線、アクセシビリティ、速度、JS無効・失敗時の成立を証跡に残す。カタログの外枠だけの改善でテーマ品質改善を代替しない。
6. 全要求と追加要求のカタログ再現、操作テスト、品質比較、公開情報検査、CIを確認する。G3や外部本番反映の承認は別の判断として扱う。

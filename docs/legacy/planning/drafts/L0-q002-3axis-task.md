## PO 判断（2026-05-01 確定）

Q-002 ローンチ順序: **同時ローンチ**

ただし単純な「両 SKU 同時リリース」ではなく、**自社サイト = Automation SEO 販売 + アフィリエイト収益 + AGENT NEO 販売 の 3 軸統合ドッグフーディングモデル** という戦略を伴う。

PO の言葉:
> 「automation SEO を販売しつつアフィリエイトで稼ぐモデルだな。これができればあとは分離するだけ。」

### 戦略の解釈（PO 確認済み）

自社サイトが両 SKU の全機能を 1 サイトで実装・運用することで、両 SKU の機能を同時に証明する。

| 収益軸 | 機能 | 実証する AGENT NEO SKU |
|---|---|---|
| Automation SEO 販売 | LP / 問い合わせ / 資料 DL / S1 受付 | **法人版機能**（HP/LP/BLP 三位一体・リード獲得・CV 計測） |
| アフィリエイト収益 | 記事 / アーカイブ / 商品カード / Sticky CTA | **個人版機能**（収益化ブロック・PR 表記・CTR 計測） |
| AGENT NEO テーマ販売 | 個人版 LP / 法人版 LP | 両 SKU の販売導線 |

「これができれば」= 自社サイトで 3 軸の運用と収益が立つ実証ができる時点。
「分離するだけ」= 自社サイトの実装が両 SKU 機能を網羅していれば、SKU 分離は技術的にはライセンス制御（REQ-F-010）の話に帰着し、機能差を新規開発する必要がない。

### 戦略的強み

- 「自分が稼いでるテーマ + AI を売る」最強の販売根拠（誠実性 + 実証）
- 開発者 = ユーザー = 販売者 が同一人物（PO 本人）→ 「両方を本当に理解している」訴求
- 1 サイト 3 収益源で運用効率も高い
- AGENT NEO 単体では作れない「Automation SEO 連携前提の機能群」が自社サイトで自然に動く

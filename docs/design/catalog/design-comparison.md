## 5. 特徴（一言で）

- **本テーマ**: 「システムとしては強いが、記事の中が素っ気ない」。theme.json 一元・配色統制・トップ完成度は最良。反面 h2/h3 が同サイズ、h2 無装飾、動き・影ほぼゼロ、部品の引き出しが少ない。**足すべきは記事内の装飾語彙（見出しスタイル・ボックス・吹き出し・ボタン variant）と h3 の階層**。
- **テーマA**: 「雰囲気で売るデザイン」。薄い色・字間 1.2px・波形グラデの MV・15 プリセットで、見た目の第一印象は最も“商品らしい”。反面 CSS 6.5k ルール・!important 840・色 156 と体系は弱く、フォント未ロード時に OS 代替へ落ちる。記事部品は入力しないと空枠。
- **テーマB**: 「編集部の道具箱」。h2 帯・33 の block style・22 ブロック・エディター設定 78 項目で記事の表現力が最大。custom props 403 で設定→変数の写像も整っている。反面 既定 MV はストック写真、領域見出し露出など初期状態の見た目は作り込み前提。

## 6. 本テーマへの設計示唆（デザイン力の観点）
1. **タイポ階層**: h3 を h2 より 1 段落とす（例 h2 32 / h3 24 / p 17）。
2. **見出しスタイル**: h2 に「帯／下線／左罫」の block style 3 種、h3 に 2 種。
3. **記事部品**: ボックス（注意・補足・引用）・吹き出し・ボタン variant（塗り／枠／矢印）・番号付きステップを block style + パターンで用意（THEME-CAT-03 と同じ受け皿）。
4. **動き**: hover の transition、カードの影 1 段、スクロール出現 1 種だけ入れる（過剰にしない）。
5. **レスポンシブ**: 600 / 782 / 960 に 1200 を足し、LP の 4 カラムを 2→1 に落とす段を持つ。
6. **プリセット**: light/dark に加え、配色 3 種程度の style variation（bridge のトークン投影と整合）。

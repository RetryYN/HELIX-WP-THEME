# AGENT NEO パーツカタログ

このカタログは、`themes/agent-neo-theme/patterns/` にあるブロックパターンと `themes/agent-neo-theme/styles/` にあるスタイルバリエーションの選択表です。パターンは非同期の静的パーツとして使い、ページの目的に合わせて組み合わせます。

## スタイルバリエーション

| slug | 性格 | 想定用途 |
|---|---|---|
| `business` | 落ち着いた青緑と業務向けの整然さ | 企業サイト・サービス紹介 |
| `dark` | 暗い背景と明るい文字の反転 | 夜間閲覧・没入感のあるページ |
| `depth` | 影と重なりで奥行きを出す | カード中心のサービスページ |
| `editorial` | 文字組みと余白を重視 | 読みもの・編集誌型メディア |
| `light` | 明るい標準配色のニュートラルさ | 初期状態・汎用ページ |
| `warm` | 生成りとテラコッタの親密な温度感 | 相談・コミュニティ・生活寄りの内容 |
| `mono` | 無彩色と直線的な強弱 | ポートフォリオ・資料型サイト |
| `vivid` | マゼンタ系アクセントの高い視認性 | キャンペーン・若い読者向けの入口 |
| `night-contrast` | 深い夜色とライムの高コントラスト | ダーク基調のプロダクト・デモページ |

各バリエーションは親テーマの既存カラースラッグを同じ集合で上書きし、フォントサイズ・間隔・影のトークンは親テーマから参照します。

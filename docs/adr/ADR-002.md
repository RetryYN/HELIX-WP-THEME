# ADR-002: 4操作面を同一JSON契約に集約

- Status: Accepted
- Date: 2026-06-14
- Phase: L2 / Gate: G2

## Context
- 本設計では `L1.1/1.2` で AI/人間の複数経路を想定しているが、`§8.7` では REST/MCP/WP CLI/UI を同一JSON契約で受ける前提を明示している。
- 単一契約に統合しない場合、重複実装・仕様差分・監査ログの不整合が生じ、運用ハザードが増える。

## Decision
- REST、MCP、WP CLI、UI の各操作面を同一のJSON契約で統一し、入出力、エラー、idempotency、dry-run/apply を共通化する。

## Consequences
- 良い面: 実装コストの重複削減、契約テストの共通化、外部連携障害時の再送・監査が簡素化される。
- 制約: 既存エージェント/ツールに合わせた変換層を設計する初期コストが発生する。

## Alternatives considered
- 操作面ごとに独立契約を保持（REST中心）する案は仕様不整合リスクを増やすため不採用。

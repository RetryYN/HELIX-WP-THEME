# ADR-018: Automation SEO連携はAGENT NEO契約を正規ターゲットにする

- Status: Accepted
- Date: 2026-06-14
- Phase: L2 / Gate: G2

## Context
- `§8.12` は AGENT NEO 側の `theme-capability` や `automation-seo fit` を中核に、ThemeB/テーマA を移行・診断・設計参考へ限定する方針。
- `§2.3` 理由では、AGENT NEO側で stable section/CTA/SEO 契約と safe apply を保持する必要を示している。

## Decision
- Automation SEO 側の正規連携先を AGENT NEO の安定JSON契約（Core Plugin中心）に限定する。

## Consequences
- 良い面: 連携品質を AGENT NEO の契約・監査モデルで統一し、深い自動改変リスクを抑える。
- 制約: ThemeB/テーマA 側の既存運用を完全に置換しないため、初期段階では適合性診断が必要。

## Alternatives considered
- 既存テーマを深いAI自動改変対象として扱う案は、DOM変化耐性と事故リスクの観点で不採用。

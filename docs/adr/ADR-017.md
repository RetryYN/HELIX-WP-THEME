# ADR-017: 市場カテゴリをAI運用型WPテーマ基盤として定義する

- Status: Accepted
- Date: 2026-06-14
- Phase: L2 / Gate: G2

## Context
- `§1.1` の目的（AIエージェント安全運用）および `§2.1` 全体構成から、単なる見た目テーマではなく運用連携基盤としての価値が要求される。
- 競合比較として既存テーマのデザイン/価格競争でなく AI操作性・監査性・LLMO計測を主価値とする戦略方針。

## Decision
- 市場ポジションを「AI運用型WordPressテーマ基盤」とし、AI編集、計測、運用品質、連携契約を中核価値に据える。

## Consequences
- 良い面: 競争軸を明確化し、差別化要素（LLMO・運用品質・契約性）を持続的に積み上げやすい。
- 制約: 初期説明コストと営業理解コストが増える。

## Alternatives considered
- 従来型WPテーマの価格・機能勝負のみで競う案は、AI操作性と運用品質という核要件が埋没するため不採用。

# ADR-011: 運用品質をJSON契約化

- Status: Accepted
- Date: 2026-06-14
- Phase: L2 / Gate: G2

## Context
- `§8.5` では監視閾値、`§8.6` では更新後検証・ロールバック、`§8.11` では運用ハザードの定常監視、`§8.7` では契約検証を明示。
- 運用品質をUI表現に任せず、契約化して可搬的に扱うことが設計全体の合意点。

## Decision
- 運用品質（更新前後診断、plugin衝突、可観測性、障害時挙動）を JSON 契約で定義し、`AgentAction/health` 系の監査を標準化する。

## Consequences
- 良い面: 監視項目の可視化、再現性のある障害分析、サポート運用の効率化が向上する。
- 制約: 契約スキーマの追加保守と運用運転監視の回し込みコストが発生する。

## Alternatives considered
- 運用品質を運用ノウハウのみで担保する案は、再現性・監査証跡の観点で不採用。

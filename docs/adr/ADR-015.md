# ADR-015: LLMOをSEO Coreの拡張ではなく独立契約にする

- Status: Accepted
- Date: 2026-06-14
- Phase: L2 / Gate: G2

## Context
- `§8.10` は answer unit、evidence graph、claim risk、AI crawler policy を `LLMO Governance` として定義。
- SEO Core が扱う canonical/schema などと、AI検索最適化（引用・根拠・CV接続）を分離する必要が文書上示されている。

## Decision
- LLMO は SEO Core の副次ではなく独立した契約領域として実装し、引用、根拠、AI露出、AI由来CV計測を専用で扱う。

## Consequences
- 良い面: AI検索・AI経由CVの要件を個別に進化させられる。
- 制約: 指標・スキーマの連携設計（answer unit と SEO データの接続）が追加される。

## Alternatives considered
- LLMO要件を SEO メタ管理に統合する案は要件分離が難しく不採用。

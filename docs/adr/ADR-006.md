# ADR-006: 速度設計はThemeB型の条件付きアセット戦略を採用

- Status: Accepted
- Date: 2026-06-14
- Phase: L2 / Gate: G2

## Context
- `§8.1` はページ種別別の条件付きCSS/JS、速度予算、重いJSの遅延化を明示している。
- 一方 `§1.2` の技術選定は FSE基盤であり、速度最適化をテーマ側責務としすぎない設計が必要。

## Decision
- ThemeBで示された条件付きアセット配布方針を採用し、必要時のみリソースを読み込む運用を標準化する。

## Consequences
- 良い面: LCP/INP/CLSなどの性能要件を満たしやすく、外部連携コードの副作用を抑止できる。
- 制約: feature flagやページ別判定の設計を維持するための配信ルール管理が必要。

## Alternatives considered
- 常時全JS/CSSを読み込む設計は初速実装は容易だが性能要件を満たしにくいため不採用。

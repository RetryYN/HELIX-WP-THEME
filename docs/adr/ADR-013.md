# ADR-013: AI運用性とクローラビリティを製品契約にする

- Status: Accepted
- Date: 2026-06-14
- Phase: L2 / Gate: G2

## Context
- `§8.8` では `data-agent-*` 系DOM anchor、snapshot、crawler access matrix、ai crawler log を前提化。
- `§8.10` の LLMO 設計や `§8.11` のリスク可視化とも整合し、AI向け可読性を機能要件として扱う。

## Decision
- AI運用性・クローラビリティを単なる運用ポリシーでなく製品契約として定義し、AI側が安全に読む/触る/公開可否を判定できるようにする。

## Consequences
- 良い面: AI編集誤差の低減、インデックス/検索露出制御の予見性向上。
- 制約: snapshot と DOM 契約の整合を維持するため更新フローが厳密化される。

## Alternatives considered
- 「必要時だけ随時対応」方式は、契約監査や自動化の一貫性が不足するため不採用。

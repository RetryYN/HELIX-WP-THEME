# ADR-009: Theme本体はSWELL型の薄いbootstrapとmodule分割を採用

- Status: Accepted
- Date: 2026-06-14
- Phase: L2 / Gate: G2

## Context
- `ADR-001` のFSE前提に加え、テーマ本体は `functions.php` 増大を避け、軽量化と分割設計を採る必要がある。
- `§8.1`/`§8.6` は更新耐性、ページ速度、可観測性を重視しており、薄いbootstrapが不整合低減に寄与する。

## Decision
- Theme本体を SWELL型の薄いbootstrap構成とモジュール分割で実装し、表示/スタイル責務を絞る。

## Consequences
- 良い面: 更新時の影響範囲を縮小でき、ブロックや資産配布の差分管理がしやすい。
- 制約: 機能追加時はモジュール接続設計と初期連結工数を増やす必要がある。

## Alternatives considered
- `functions.php` を肥大化させる集中実装は保守性を下げるため不採用。

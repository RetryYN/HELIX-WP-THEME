# ADR-008: Theme CoreとCompanion Pluginを分離

- Status: Accepted
- Date: 2026-06-14
- Phase: L2 / Gate: G2

## Context
- `§2.4 配布境界` は、`agent-neo-theme` と `agent-neo-core-plugin` の責務を明確に分離し、保持データ・API・計測・SEO をコアプラグイン側に寄せる構成を示している。
- `§8.6` の運用・更新・可用性設計、`§8.7` の API/自動化契約設計とも、表示層と制御層分離で複合事故を減らす前提になっている。
- `§2.3` 理由は WordPress plugin territory・移植性・保守性の観点。

## Decision
- Theme Core と Companion Plugin を明確に分離し、見た目とデータ/契約/計測/ジョブ実行は Core Plugin が所有する。

## Consequences
- 良い面: テーマ審査/配布上の責務境界が明確になり、データ移植・保守・監査がしやすい。
- 制約: 配置先が分かれる分、導入・更新手順とライセンス制御の実装が追加される。

## Alternatives considered
- すべてをテーマ内に詰める案は、plugin territory違反、運用事故、更新耐性の点で不採用。

# ADR-016: SEO/WP運用の不都合な真実をrisk-ledgerとして製品化する

- Status: Accepted
- Date: 2026-06-14
- Phase: L2 / Gate: G2

## Context
- `§8.11` は canonical/noindex/robots/sitemap、cron、cache、plugin conflict、update、privacy、AI snapshot 等をリスクとして記録する体制を示す。
- `§10 リスクと対策` でも同様の静かな事故領域を明確化しており、事前監視対象とする意図が一致している。

## Decision
- SEO/運用上の地雷的変更を `risk-ledger` に明示し、検出・対策・残リスクを契約として公開可能な形で管理する。

## Consequences
- 良い面: 予防保守・復旧判断が容易になり、SLA運用の説明責任を果たしやすくなる。
- 制約: 常時監視とハザード分類の運用品質工数が増加する。

## Alternatives considered
- リスクを運用ナレッジに留める方式は、再現性と監査性が不足するため不採用。

# ADR-014: テーマ品質/配布準備をP0契約にする

- Status: Accepted
- Date: 2026-06-14
- Phase: L2 / Gate: G2

## Context
- `§1.2` 以降の全体設計で販売テーマとしての品質要件（テーマ審査、a11y、i18n、release、SBOM等）を明示。
- `§8.9` は Theme Review・Accessibility・Release/SBOM・hosting互換・privacy・SEO索引・support docs の一体的ゲートをP0級に位置づける。

## Decision
- テーマ品質／配布準備を P0 契約として先に定義し、実装前提で受入れる。

## Consequences
- 良い面: リリース後の商用リスクを低減し、品質ゲートでの再作業を減らせる。
- 制約: 開発初期からテスト資材・配布証跡を用意するため初期負荷は高くなる。

## Alternatives considered
- 実装完了後に品質ゲートを追加する後追い方式は、テーマ配布失敗リスクが高いため不採用。

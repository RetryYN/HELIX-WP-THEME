# ADR-007: LPとHPは別ブループリントとして設計

- Status: Accepted
- Date: 2026-06-14
- Phase: L2 / Gate: G2

## Context
- `§8.3` は LP（CV寄与）と HP（ブランド/回遊）を異なる目的・構成で設計し、`section_id` を前提に改善導線を分離する。
- 成功指標（CVと信頼/回遊）が異なるため、1つの設計で同時最適化しづらい。

## Decision
- LPとHPを別ブループリント（`lp-blueprint` / `home-blueprint`）として扱い、要件別のセクション設計と計測導線を持たせる。

## Consequences
- 良い面: AI主導の改善時に評価指標ごとの最適化が容易になる。
- 制約: テンプレート/コンポーネント分岐が増える。

## Alternatives considered
- LP/HPを共通テンプレートで一体化する案は、用途別KPI最適化を阻害するため不採用。

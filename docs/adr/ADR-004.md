# ADR-004: 参照テーマは設計抽象のみ取り込む

- Status: Accepted
- Date: 2026-06-14
- Phase: L2 / Gate: G2

## Context
- `§1.3` の制約として参照テーマのコード/画像/CSS流用を行わない方針がある。
- `§8.13` でも、既存テーマアセットの移送や再利用を避ける理由（ライセンス・競合・復旧リスク）を明確化している。

## Decision
- 他テーマの具体実装（コード/画像/CSS）は取り込まず、機能やUXの抽象（デザイン原則・情報設計・構造）に限定して参照する。

## Consequences
- 良い面: ライセンス・著作権リスク、競合化リスク、運用負債の増大を抑えられる。
- 制約: 外形的な見た目の高速模倣はできず、独自設計コストが必要。

## Alternatives considered
- 参照テーマ資産の再利用（CSS/画像/実装パターンそのもの）案は、実装加速より法務・更新負荷リスクが大きいため不採用。

# ADR-019: Automation SEO Theme Bridge Pluginは診断・正規化・移行入口に限定する

- Status: Accepted
- Date: 2026-06-14
- Phase: L2 / Gate: G2

## Context
- `§8.13` は既存テーマ側の深い書き換えを避け、diagnostic/normalizer/migration blueprint として運用する設計を示す。
- `§2.3` 理由では、既存テーマDOM/CSS/SEO meta の不安定性を根拠に deep write を避ける意図が明示されている。

## Decision
- Bridge Plugin は既存テーマの診断、正規化、移行入口に限定し、AGENT NEO本体（Core Plugin）を正規 write target とする。

## Consequences
- 良い面: 既存テーマ移行時の破壊的変更を抑止し、移行品質を高める。
- 制約: 自動化で実施できる範囲が限定されるため、完全自動最適化は段階的に実装する必要がある。

## Alternatives considered
- 既存テーマへの深い自動書き換えを標準化する案は、保守性と復旧性の観点で不採用。

# ADR-012: API/自動化は契約ファーストでCore Pluginが所有

- Status: Accepted
- Date: 2026-06-14
- Phase: L2 / Gate: G2

## Context
- `§8.7` は Core Plugin 側に OpenAPI/JSON Schema/ジョブ契約を置く構成を定義し、REST/MCP/WP CLI を同一仕様で扱うことを明示。
- `§2.4` で Core Plugin は REST/MCP/CLI/SEO/計測などの実行責務を担う設計で、Themeは表示に留める。
- `§8.7` の catalog-update 障害設計も producer/consumer 契約を前提とする。

## Decision
- API と自動化の実装・契約所有権は Core Plugin に集約し、テーマ側には持たせない。
- 自動化系イベントは idempotency、replay 防止、dead_letter などのジョブ状態を伴う契約で設計する。

## Consequences
- 良い面: API更新の破綻リスクを抑制し、4操作面（REST/MCP/CLI/UI）の一貫性を維持できる。
- 制約: 変更時の影響範囲が Core Plugin 側に集中するため、契約版管理が重要になる。

## Alternatives considered
- テーマ側に API/Cron 状態を寄せる案は plugin territory と更新耐性の観点で不採用。

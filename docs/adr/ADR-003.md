# ADR-003: Automation SEOは別課金

- Status: Accepted（一部 Superseded-by: ADR-024）
- Superseded-by: ADR-024（部分: 配布・課金モデル / 2026-06-18）
- Date: 2026-06-14
- Phase: L2 / Gate: G2

> **【注記 2026-06-18】** テーマ単体販売・買い切り価格の前提は ADR-024（Automation SEO 専用配布・単体販売廃止・REQ-F-043廃止）により改訂。価格/配布モデル部分のみ supersede であり、AI 操作スコープ差に基づく機能境界の分離（テーマ本体 vs. Automation SEO 別課金の責務切り分け原則）は ADR-024 後も引き続き有効。

## Context
- `1.1` の目的で「AI原価をテーマ買い切り価格に内包しない」ことを明示しており、価格設計と収益安定化に直結する。
- テーマ基盤自体は商用テーマとして安定運用を担保し、AI生成型外部サービスは別契約を前提とする。

## Decision
- Automation SEO の利用は別課金化し、テーマ本体の買い切り価値と切り分けて提供する。

## Consequences
- 良い面: テーマ単価の採算構造が明確化し、AI原価増減の影響を本体価格から分離できる。
- 制約: 連携ユーザーの初期導入手順が増える。

## Alternatives considered
- テーマ価格にAI原価を一体化する案は、想定外の価格変動と事業リスクが大きいため不採用。

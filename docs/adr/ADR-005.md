# ADR-005: SEOはテーマA型の統合UXを採用

- Status: Accepted
- Date: 2026-06-14
- Phase: L2 / Gate: G2

## Context
- AGENT NEO の目的はAIがSEOメタ/OGP/canonical/noindex/schemaを一括で操作可能にすることにあり、`§8.2` の `SeoProfile`・`SeoMeta` 管理設計と整合する。
- テーマA由来のUX要素（ファーストビュー・プリセットなど）を統合し、ThemeB側のJSON-LD品質を補完する意図が記述されている。

## Decision
- SEO関連体験は テーマA型の統合UXを採用し、AIが一連のSEO情報を1トランザクションで扱える形に整える。

## Consequences
- 良い面: SEO操作の一貫性が向上し、`Agent JSON API` での一括更新・監査が容易になる。
- 制約: 既存メンテナンスフローとの整合を取るため、移行初期は既存設定の吸収ルール整備が必要。

## Alternatives considered
- 既存テーマごとのSEO実装を独立最適化する案は、AI側契約と乖離しやすいとして不採用。

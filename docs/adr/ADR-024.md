# ADR-024: 配布・課金モデルを Automation SEO 専用配布に一本化する

- Status: Accepted
- Date: 2026-06-18
- Phase: L2 / Gate: G2（PO 確定 / 事後記録）
- Decided by: PO
- Supersedes: L1 §2 製品ライン（3 SKU）、REQ-F-043（Open Editor Bridge Plugin）、`docs/design/L2-design.md`（旧販売前提・REQ-F-043 carry）、`docs/security/threat-model.md` TB-11/TB-12（Bridge 経由 write 例外）
- Related: ADR-008（Theme Core と Companion Plugin の分離）、REQ-F-042、REQ-NF-025、GAP-RT-053

---

## Context

### 背景

L3 詳細設計の実テーマギャップ精査（GAP-RT-053）において、REQ-F-043「Open Editor Bridge Plugin」の
OAuth 申請フロー・scope 制限・審査フロー・revoke 手順が全て未定義であることが発覚し、PO エスカレーション
論点として保留されていた。

あわせて L3 ゲート直前の設計レビューで、以下の構造的課題が顕在化した。

1. **trust boundary の二重化**: Automation SEO 経由の write（aseo/v1）と、外部 AI エディタ経由の write
   （Bridge Plugin = REQ-F-043）が並立すると、trust boundary が 2 系統に割れる。Bridge 側の OAuth 管理・
   互換性保守・セキュリティ追従コストが独立して発生する。

2. **標準テーマ 3 SKU の課金モデルの複雑さ**: 個人版（¥19,800）/ 法人版（¥98,000）/ 移行プラグイン
   （無料）という 3 SKU 構成では、テーマ価格に AI 原価が混入するリスクがある。Automation SEO の利用量課金
   モデルと整合しない。

3. **wp.org 審査・ライセンス検証の負担**: Q-005（ライセンス検証方式）・Q-006（wp.org 機能ロック粒度）は
   テーマ単体販売を前提に設計コストが積み上がっていた。

2026-06-18、PO が上記を総合判断し、配布・課金モデルを抜本的に変更する意思決定を確定した。

---

## Decision

PO 確定（2026-06-18）の内容を以下の通り記録する。

### 1. Automation SEO 専用配布に一本化

AGENT NEO テーマは **Automation SEO 契約者への専用配布テーマ** として位置づける。
テーマ自体では課金せず、テーマへのアクセス権は Automation SEO の有効契約をもって付与する。

### 2. 標準テーマ SKU（個人版・法人版）の単体販売を廃止

L1 §2 で定義していた下記 SKU を廃止する。

| 廃止 SKU | 旧価格 |
|---|---|
| 個人版（標準テーマ単体） | ¥19,800（買い切り想定） |
| 法人版（標準テーマ単体） | ¥98,000（買い切り想定） |

「AI 原価をテーマ価格に抱えない」「本丸は Automation SEO、テーマは GPL 配布面」という整理に従い、
テーマは Automation SEO 契約に付帯する配布物として扱う。

### 3. REQ-F-043 Open Editor Bridge Plugin の廃止

外部 AI エディタ（Claude Computer Use / Codex CLI / Cursor / Cline / Continue 等）向けの
有料アドオンプラグイン（REQ-F-043）を廃止し、**AI の write 操作経路を Automation SEO 経由のみ**に限定する。

外部 AI エディタからの直接書き込みはデフォルト拒否のまま（REQ-F-042 は存続）。

### 4. 個人 / 法人のスコープ差（機能境界）は維持

個人版: 記事 CRUD のみ（テンプレート構造変更不可）
法人版: 記事 CRUD + HP / LP / 固定ページ構造変更

この機能スコープ差は AI 操作の操作許可リスト（agent-api の許可スコープ）として機能境界を維持する。
ただし課金のひも付けは標準テーマ SKU ではなく **Automation SEO プラン階層** へ移管する。
具体的なプラン対応定義は Automation SEO 側で別途確定（follow-up: 本 ADR §Follow-up 参照）。

### 5. 移行プラグイン（無料）は維持

移行プラグイン（wp.org リード・マグネット）は無料で維持する。
Automation SEO への導線として位置づけ、機能スコープは診断・正規化・移行入口に限定する（ADR-019 参照）。

---

## Consequences

### 良い面

- **trust boundary の単一化**: AI の write 操作経路が Automation SEO 経由のみになり、外部 AI write 面がゼロになる。
  セキュリティモデルが大幅に単純化し、監査・ロールバック・ログが一元化する。

- **GAP-RT-053 が消滅**: REQ-F-043 の OAuth 申請フロー・scope・審査・revoke の未定義問題が根本解消される。
  L3 PO-ESCALATION の残課題がひとつ RESOLVED になる。

- **Q-005・Q-006 の大幅単純化**: テーマ単体販売を前提としたライセンス検証方式（Freemius 等）と wp.org 機能ロック
  粒度の PO 裁定論点が消滅または縮小する。wp.org 審査対象は移行プラグインのみに限定される。

- **課金導線の集約**: テーマ購入・AI 利用料・プラン管理がすべて Automation SEO に集約され、
  ユーザーの決済フローが一本化する。

- **開発範囲の縮小**: Bridge Plugin（OAuth / 外部エディタ認証認可 / 互換性テスト）に関する
  L4 以降の実装・保守コストが削除される。

### 制約・トレードオフ

- **標準テーマ単体収益の喪失**: 個人版・法人版の一括買い切り収益を手放す。
  Automation SEO サブスクリプション継続が唯一の収益源になる。

- **個人 / 法人スコープの課金管理が Automation SEO 側に依存**: 操作スコープ差（記事 CRUD vs 構造変更）の
  ライセンスゲートは Automation SEO プラン設計が確定するまで実装上のプレースホルダーとなる。

- **GPL 配布の継続**: AGENT NEO テーマは GPL ライセンスで配布されるため、コードは引き続き公開状態になる。
  AI 判断ロジックは REQ-NF-025 に従い Automation SEO 側に集約することで保護を維持する（従来方針と同じ）。

- **REQ-F-043 関連の ACC がすべて無効化**: ACC-043 / ACC-043a / ACC-043b はテスト計画から削除対象になる。
  L4 テスト計画更新時に対応が必要（他 Wave 担当）。

---

## Alternatives Considered

### 案 A: REQ-F-043 を PO 裁定後に継続実装

OAuth 仕様確定後に Bridge Plugin を実装する案。trust boundary 二重化とメンテナンスコストは残る。
「外部 AI write 受口を持つことがセキュリティモデルとして複雑すぎる」という判断により不採用。

### 案 B: テーマ単体販売を維持しつつ Automation SEO を optional 連携に

標準テーマ 3 SKU を残し、Automation SEO を任意追加オプションとして位置づける案。
AI 原価をテーマ価格に含めると利益率が不安定になる。Automation SEO が「本丸」であるという製品戦略と逆行するため不採用。

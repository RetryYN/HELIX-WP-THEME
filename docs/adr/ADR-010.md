# ADR-010: デザインは見た目コピーではなく失敗しにくいUI思想を契約化

- Status: Accepted
- Date: 2026-06-14
- Phase: L2 / Gate: G2

## Context
- `§8.4` は見た目の忠実複写ではなく、情報設計の抽象化・堅牢UI（プリセット、構成）を前提にしている。
- `§3.3` の要件でも設計抽象とLP/HPの用途差に基づく画面構成が示され、AI改善の前提となる。

## Decision
- 参照テーマの見た目コピーを避け、失敗しにくいUI思想（構成の型、リスク監査、CTA導線）を契約として定義する。

## Consequences
- 良い面: AIが編集時に壊れにくく、改善提案が再現性高く実装される。
- 制約: 初期印象としては独自性が出るまで時間を要し、デザイン作業の説明コストが増える。

## Alternatives considered
- テーマの画面を模写する方針は、ブランド/運用差異とAI修正安定性が低いため不採用。

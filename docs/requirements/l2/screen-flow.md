# L2 Screen Flow

## 通常

`WT-UI-01 パターン選択 → 差し替えプレビュー → 構造差分確認 → 保存 → WT-UI-07 ゲート → WT-UI-05 / 06 公開面確認`

値の編集は `WT-UI-04 値入力 → 安全域 / 生値 / 破壊域の判定表示 → 保存（破壊域は停止）` を経る。

## 取消

差し替え・値入力を保存前に取り消した場合は theme.json・テンプレート・option に何も書かず、編集前の状態へ戻る。

## failure

ゲート FAIL は対象ファイル・ゲート ID・原因（生値、参照欠落、尺度再定義、Block validation invalid）を示し、修正の再入場条件を出す。
破壊域停止は「どの規則に、どの値が、どの境界で」触れたかを示し、権限による解除手段を提示しない。

## timeout/recovery

実機ゲート（G-E1）の docker 起動 timeout は再実行で同一結果を返す。途中結果を pass として扱わない。

## navigation

Site Editor の各面（パターン・スタイル・パーツ）へは WP 標準ナビゲーションで到達し、テーマ独自メニューを追加しない。

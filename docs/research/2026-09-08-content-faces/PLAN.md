# 独立コンテンツの代表再現

状態: 実行中。全要求再現計画の段階B。WT-FR-PAID-01 / INTERVIEW-01 / BLP-01 の6 ACを対象とする。

## 観察からの試作判断

公開プレビューと会員権限は別軸である。プレビュー境界より後の本文を未購入者へ配信せず、会員であっても対象の権限がなければ試し読みを表示する。公開レスポンス・REST・検索・feedを含めて検査する。見た目の違いだけで認可を実証しない。

WordPressのCPT登録はプラグイン側で行い、テーマ変更で管理単位が失われないようにする。試作専用プラグインは宣言・コンテンツ管理と外部権限サービスのfixtureを持つ。テーマは受け取った表示データだけをレンダリングする。決済・購読契約を成立させる処理は持たない。

インタビューは人物・所属・発言・掲載確認を結び、独立詳細と参照カードを同じ投稿から描画する。BLPは問題理解・判断材料・適否からLPへ送り、LPは申込導線を主にする。独自設定は非表示とは区別する。

## 再現・証拠

- 別DB・別WordPress・loopback公開で既存試作環境と分離する。
- 買い切りと購読、未購入・対象購入済み・別商品購入済み・購読失効を別アカウントのfixtureで実行する。
- 一覧・販売案内・試し読み・購入本文をPC/SPで撮影し、同一本文と同一viewportの標準案・改善案を比較する。
- 独立管理、埋め込み参照、BLP→LP遷移をブラウザとWordPressのデータから検証する。
- 実サービスへの接続は未検証として残す。PoCの成功を製品のアクセス制御全体の完了にしない。

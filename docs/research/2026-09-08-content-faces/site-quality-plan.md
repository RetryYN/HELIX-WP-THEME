# 常設案内の操作領域と変更前後比較

対象要求はWT-NFR-SP-01。既存の常設11面をPC1440px/SP375px・JS有効/無効で計測する。本文16px以上、リンク44px以上、ページ横溢れなし、キーボードでスキップリンクを視認・操作して本文へ移動できることを確認する。共通設定と全ページ種別・固定面・同意バーを含む要求全体の完了とは扱わない。

4f7851dの会社案内で、ロゴの高さ約39.5px、料金リンクの幅約34.7px、目次とフッターの高さ約40.7pxを実測した。既存のtheme.jsonにある`custom.tap-min`を共通尺度として使用し、ナビゲーションとロゴの操作領域を確保する。本文や見出しを大きくすることで代替しない。

[W3CのTarget Size (Enhanced)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced)は44×44 CSS pxと例外を説明する。これはAAAの条件であり、AAの下限と混同しない。本試作は自らの要求にある44pxを採用する。文中リンクは今回の常設面にはないため、独立した操作リンクを検査する。

`node scripts/verify-site-page-quality.mjs --baseline`で変更前、通常実行で変更後を保存する。会社案内と料金は同じデータ・同じ画面幅で撮影する。測定と画像を比較し、操作面積と折返しへの影響を確認する。速度・CWV・全面の美観向上はこの計測では証明しない。

## 結果

変更前265検査中44失敗、変更後265検査すべて成功。失敗は各表示条件のタップ対象寸法であり、370はJS有無等を含む延べ測定件数。本文・横溢れ・スキップ移動は変更前も成立した。会社案内・料金のPC/SP画像8枚を保存し、カタログから比較画面へ移動できる。カードの料金項目の整列と編集UIは既存検証も再実行する。

# CV・ユーザビリティの根拠つき設計ルール集（L2 探索証跡）

- 作成: 2026-09-05
- 入力: 4 系統の一次調査（U = ユーザビリティ研究 / C = CRO 実験 / D = OSS デザインシステム / S = 標準・動き・性能。原出典 URL を含むためリポジトリ外で保持）と、WP-THEME のパーツ台帳（`docs/research/2026-09-04-parts-inventory/README.md` および `docs/research/2026-09-05-parts-pattern-taxonomy/README.md`）
- 位置づけ: L2 探索証跡。要求の確定でも設計（L4）の決定でもない。§2「既定値の提案」は Claude 案で PO 判断待ち。
- 対象: 日本の中小事業者向け WordPress テーマ（LP・コーポレート・ブログ/メディア・比較媒体）

---

## 0. 読み方

### 0-1. 証拠強度

| 強度 | 定義 | 例 |
|---|---|---|
| **A** | 規格本文（W3C 等）、統制実験・A/B、査読論文、大規模アイトラッキング/ベンチマーク | WCAG 2.2、NN/g 定量テスト（n≥100）、EC の UX 調査会社 ベンチマーク、web.dev の A/B 事例 |
| **B** | データを伴う専門家ヒューリスティック、公開デザインシステムの設計方針、ベンダー公式ガイド、統制なしの実サイト計測、規制当局文書 | NN/g 指針記事、GOV.UK/USWDS、Google 公式ガイド、消費者庁資料 |
| **C** | 単一事例・実務者の意見・ベンダー集計の孫引き | 「+300%」型の事例記事、効果量が非公開の A/B 事例集 |

- A/B 強度を優先して収録。C は「それしか証跡がない」場合のみ残し、**要自社検証** を付す。
- 一次出典を確認できなかった二次資料の数値（例: 「フォーム 8 項目超で 1 項目ごとに 4–6% 低下」「2 回超の表示で直帰 +40%」「自然域タップ精度 96% vs 61%」「80 字超は 41% 飛ばされる」）は各証跡集で不採用にしており、本書にも載せない。

### 0-2. p-hacking の注意（C-F00）

商用 A/B テスト 2,101 件の回帰不連続分析（Berman, Pekelis, Scott, Van den Bulte, Wharton, 2018, https://papers.ssrn.com/sol3/papers.cfm?abstract_id=3204791 ）では、約 73% の実験者が正の効果が 90% 信頼水準に達した時点で停止し、約 75% の効果は真に null、optional stopping により偽発見率が 33%→40% に上がる。したがって、

- 個別事例の「+N%」は割り引いて読む。C 強度の数値は要求の根拠にしない。
- テーマは「勝ちパターンを焼き込む」のではなく、各パターンを ON/OFF・variant（S10）として提供し、サイト側で検証できる形にする。

### 0-3. 数値の規律

**数値は出典本文にある値のみ。無ければ「数値なし」。** 推定値・換算値を書くときは「PoC で計測」と明記して数値の出所を分ける。

### 0-4. ID と列の意味

- 根拠 ID: `U n-m` = ユーザビリティ研究の節、`C Fnn` = CRO 実験、`D X-n` = デザインシステム、`S F-nn` = 標準・動き・性能（いずれもリポジトリ外の一次調査の ID。C 強度の項目は一次調査側でも 要自社検証 扱い）。
- 「テーマでの反映」列は、パーツ台帳の選定軸 S1〜S10（S1 style variation / S2 block style / S3 パーツ案 / S4 テンプレ変種 / S5 slot・ゾーン / S6 投稿メタ / S7 設定 JSON / S8 device 差分 / S9 正本参照 / S10 variant）と、既定値・guard（CI/lint/ゲート）で書く。
- 「関連 Issue」は WP-THEME リポの Issue 番号（台帳の対応から）。

---

- 「テーマでの反映」列は証跡ではなく Claude の設計提案（PO 判断待ち）。証跡は「ルール・強度・出典・数値」の 4 列。

- 商用 SaaS / マーケティングツール / CRO・解析ベンダーと、その事例企業名は本書では一般語（「マーケティングツール社の集計」「通信会社の事例」など）に置換した。原出典との対応表と 4 系統の一次調査（usability / cro / design-systems / standards）はリポジトリ外（作業者ローカル）で保持し、公開リポジトリには置かない。
- テーマ A / B・参照サイト・実サイト調査の固有名は台帳と同じく伏せ字。本書には含めていない。

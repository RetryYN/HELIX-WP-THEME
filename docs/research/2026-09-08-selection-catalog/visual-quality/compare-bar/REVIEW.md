# 狭幅比較バーの操作性改善

## 観察と設計

既存の比較バーは候補名、`すべて外す`、`比較する`を一つの横方向グリッドに置いていた。320pxでは候補名が増えると操作ボタンへ残る幅が小さくなり、固定バー内の操作対象を見分けにくい。比較バーの情報・動作は変えず、420px以下だけ見出しと候補を上段、2つの操作を下段へ揃えた。

## 変更前後の証拠

| 観察 | 変更前 | 変更後 |
| --- | --- | --- |
| 320px比較バーの列 | 1fr + auto + auto の同一行 | 見出し/候補と操作2列を分離 |
| 操作ボタン | 内容幅に依存 | 各列幅いっぱい、44px以上を維持 |
| ページ横溢れ | 既存の候補横スクロールを維持 | `scrollWidth <= innerWidth` を検査 |

ブラウザ回帰 `narrow comparison bar keeps both actions visible beside selected candidates` は、320pxで3候補を選択し、バー内の横溢れなし、両操作の表示、画面下端内を確認する。既存の比較選択・解除・ダイアログ回帰も同時に実行する。

## source digests

`catalog.css` と `selection-catalog.spec.ts` は検証実行時にSHA-256を再計算し、同じ変更へ束縛する。撮影内容や候補データ、要求件数、判断状態は変更しない。

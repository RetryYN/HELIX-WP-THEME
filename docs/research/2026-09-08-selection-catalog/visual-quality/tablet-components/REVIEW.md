# タブレット幅の共通部品を読み比べる

基準: ecca471、2026-09-20。専用サーバーで390/768/1440pxを目視監査した。
768pxでは左ナビを保持した2列の共通部品画像が215pxまで縮小し、390pxの画像340pxより小さい。フッターの列構造などが判別しにくい。

既存カタログの比較しやすさを改善するため、701〜1000pxでは共通部品を1列とする。サイドバー・検索・操作・候補の意味は保持し、1000pxを超える幅は既存2列。狭いコンテンツ領域で列を組み替える判断は [WAI Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) を参考にした。WCAG適合全体の宣言ではない。

`capture.mjs` は基準commitのCSSをbeforeに使用し、現在のCSSをafterとして画像読込完了後に390/768/1440pxを撮影する。PNGと寸法記録で確認する。

結果: 768pxの画像幅215→468px。390pxは340px、1440pxは530pxを維持。全撮影幅で横溢れなし。既存selection-catalog/filter E2E 33件と、701/768/1000/1001/1440pxの列境界を検証する新規1件が成功。画像内の微細文字を原寸で読む用途は引き続き詳細ビューを使う。全候補の目視網羅や全要求完了は未達。

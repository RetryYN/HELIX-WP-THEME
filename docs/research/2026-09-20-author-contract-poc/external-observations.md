# 外部観察

- Schema.org の `Article.author` は Organization または Person を受け取るが、このテーマ契約では編集責任を個人正本へ固定する。<https://schema.org/Article>
- Schema.org の `Person` はプロフィール情報の型として `url` / `image` / `sameAs` などを持てる。<https://schema.org/Person>
- `ProfilePage` はプロフィールページの主対象を構造化する型であり、著者アーカイブの正本と結び付ける。<https://schema.org/ProfilePage>

これは Schema.org の型境界を確認する観察であり、検索結果の適格性や法的表示の保証ではない。

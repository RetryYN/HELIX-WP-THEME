# PR表記の自動判定・表示境界 PoC

`WT-FR-VOCAB-03` の未検証部分を、既存の試作03実装と実機証跡へ再束縛する静的契約PoC。広告パーツ・アフィリエイトリンク・商品リンク・広告creativeを含む記事だけに、PO決定の「本記事にはプロモーションが含まれます。」を記事上部へ一箇所表示し、対象外記事への誤表示、本文編集による削除、サイズ/コントラスト不足、CTA/バナー隣接を負例で拒否する。

```bash
node scripts/verify-pr-disclosure-contract-poc.mjs
```

既存の `wt_content_has_pr_disclosure()` が持つ先頭3段落・600字・否定文除外の境界も正例と負例に投影する。本文の既存表記との重複抑止は確認するが、欠落防止と同時にどこまで強制するかは要求の `pending_resolution` として残す。法令適合をこのPoCが断定することはない。

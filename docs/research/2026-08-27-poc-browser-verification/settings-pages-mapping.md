## 写像ルール

| 写像先 | 本テーマ側の受け皿 | 可否 |
|---|---|---|
| 表示・機能 ON/OFF（A 81 / B 35） | テンプレ／パターン有無（THEME-JSON-03 の差し替え規約）＋ options JSON | 可（意味論は規約次第） |
| デザイントークン（B エディター設定 78） | theme.json palette / fontSizes / block style（マーカー・ボーダー・ボタン・アイコンボックス・吹き出し色） | 可・機械変換 |
| SEO/テンプレ条件（A 20 / B 19） | noindex 条件・canonical・JSON-LD ON/OFF → options JSON + head 出力の条件分岐 | 可 |
| 計測・広告・外部コード（A 35 / B 17） | HELIX / プラグイン側（REQ-NF-025 でテーマ外） | テーマ外 |
| 性能（B 3） | サーバ／キャッシュプラグイン | テーマ外 |
| その他 options（A 38 / B 1） | options JSON | 可 |

## 結論
- カスタマイザー分（A 1,045 / B 520）と合わせた母数は **A 1,219 / B 677**。テーマ外へ逃がすもの（計測・広告・性能: A 35 / B 20）を除き、**値は全て JSON 化可**。
- 本テーマに無い概念は「表示 ON/OFF 系」（A 81 + カスタマイザー 125、B 35 + 136）で、これが THEME-JSON-03 の差し替え規約の母数。

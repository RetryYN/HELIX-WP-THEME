## 詰めた結果（設計方針の提案）

1. **ヘッダー**: 3 テーマとも「ロゴ + ナビ + 右端 CTA/検索」の 1 行構成で差は小さい。B の「ヘッダー内部」ウィジェットと「お知らせバー」を header part 内の slot として持てば吸収できる。
2. **フッター**: 本テーマは 3 カラム固定。A/B はウィジェット 1〜5 領域。→ footer part を「カラム数可変の領域」に変え、footer-credit を残す。
3. **サイドカラム**: 本テーマに実体がない（子テーマの 2 カラム化のみ）。A/B は共通／追尾／トップ専用／スマホ版の 4 種。→ `parts/sidebar.html` と `parts/sidebar-sticky.html` を新設し、テンプレ変種（single-2col / single-1col）で有無を切替。
4. **モバイル**: 3 テーマともハンバーガー。B は下部固定メニュー（18 control）を持つ。→ `parts/mobile-bottom.html` を任意パーツとして新設。
5. **記事周辺の共有 slot**: 本文前・関連記事前後・固定ページ上下の slot が本テーマに無い。→ single.html / page.html に空の template-part slot を置く（空なら描画されない）。

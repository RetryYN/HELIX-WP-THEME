## 3. 目視所見（同一コンテンツで並べて初めて見えた差）

- **本テーマ**: 12 種別すべて必須充足。記事は 2 カラム + 記事末 CTA/著者/関連/前後/コメントまで一列に揃う。PR 表記の自動出力だけが無い。
- **テーマA**: 独自ブロックは既定値では「空の枠」として描画されるものが多く（リッチメニュー・吹き出し・比較表など）、**内容を入れないと部品が見えない**。前後記事ナビが無い。著者アーカイブに h1 が無い。コメント欄の直後に **PHP Warning が画面に出る**（テーマの customizer 設定ファイル由来。INV-13-F1 と同系統、フロント側でも再現）。
- **テーマB**: 20 領域すべてにウィジェットを置くと記事ページが「領域見出し」で埋まる。追従シェア・記事スライダー・ピックアップバナー・お知らせバーが ON で動作。前後記事ナビは検出されず（設定 ON でも既定デザインでは class 不一致の可能性）。固定ページ本文の判定が落ちたのは検出器側（body class 由来）。
- 3 テーマとも PHP エラー 0（A のフロント Warning は本文テキスト側で検出）、JS 例外 0、横スクロール 0。

## 4. 同一化のために本テーマへ足すもの（構築で確定）

1. PR 表記の自動出力（投稿メタ／カテゴリ条件）— B は ON で動作、A も ON 可
2. 追従シェア（B）
3. お知らせバー・記事スライダー・ピックアップ（B、トップの「あれば」）
4. ウィジェット相当の共通 slot（本文前・関連前後・固定ページ上下・フッター可変）— A 10 / B 20 領域に部品を置いた結果、**本テーマだけ置き場が無い**ことが可視化された

## 5. 再巡回で確定した追加所見（再構築後）

- **本テーマのヘッダーナビは theme part にハードコード**（`parts/header.html` 内の `navigation-link` 3 件）。`wp_navigation` 投稿を更新しても反映されず、A/B の「メニュー割当」に相当する JSON 操作面が無い。→ THEME-CAT-01 に「header の navigation を `ref` 化」を追加。
- **本テーマに目次が無い**（P02 で唯一の必須欠け。初回巡回の toc=✓ は検出器の誤検出）。A/B は標準装備。
- テーマB トップ: 記事スライダーを ON にすると `Undefined variable $thumb` の PHP Warning が **3 件画面に出る**（アイキャッチ無し記事があるケース。全記事にアイキャッチを付けても出るため補足記事側の条件）。
- テーマA 記事: `Trying to access array offset on false` の PHP Warning が **1 件画面に出る**（カスタマイザー設定ファイル由来、INV-13-F1 と同系統）。
- 3 テーマとも JS 例外 0、横スクロール 0。必須充足は 本 77/78・A 76/78・B 77/78。

## 2. 日本サイト特有

- **縦書き・縦組みが独立カテゴリとして成立**。ギャラリー A は 164 件、ギャラリー B も複数ページ分を収録し、旅館・温泉・和菓子・寺社・美術館・法律事務所・学校・工務店など、
  「和の印象・格式・余白」を必要とする業種で使われる。全文縦書きではなく「見出しのみ縦、本文は横」が実務上の推奨 [11][12][10]。
- **明朝の役割が海外セリフ復権より明確**。明朝 = 和風・高級感・信頼（金融・法律・医療・教育）。英語セリフ体と組み合わせて統一感を出す指針が制作会社側で共有されている [8][9][10]。
- **英字見出し + 和文本文の 2 言語構成**。英字（Roboto / Inter / Montserrat / Space Grotesk 等）を「見せる文字」、和文（Noto Sans JP / 游ゴシック / ヒラギノ）を「読む文字」とし、
  x-height と字幅を揃える。採用サイトの英語コピー（"We hire problem solvers."）が例示される [5][8][10]。
  ※「英語大 + 日本語小」という比率そのものを明示したトレンド記事は今回の出典には無く、ギャラリーの事例と組み合わせ指針から読み取れる範囲に留まる。
- **手書き風・モダンゴシックの二極**。国内フォント記事は手書き風（Hachi Maru Pop 等）とモダンゴシック（Noto Sans JP, BIZ UDP）を同時に推す。UD フォントの a11y 文脈が強い [8][9]。
- **韓国発の意匠影響**。国内制作会社が「韓国デザイン」「短尺動画・写真 SNS 文法」（要素を大きく密に、ずらしたネオン）を明示的に参照 [6]。
- **企業サイト向けの保守的翻訳**。国内の企業サイト向け記事は「ダーク = 高級」「本物の写真」「Bento」「余白」など、海外トレンドを CV と信頼性に寄せて解釈する [4][2]。
- **ギャラリー文化**。ギャラリー B / ギャラリー A / ギャラリー C は「縦書き」「タイポグラフィ」「動きあり」等のタグで検索でき、国内の表現決定はギャラリー参照が前提になっている [11][12]。

## 5. 外部トレンドとの突き合わせ

記事 23 出典が「既定」と書く bento（実測 1%）、glass（3%）、3D（8%）、kinetic type、marquee（5%）は実サイトでは 1 桁 %。海外の実務検証記事も性能（CWV・FPS・JS 重量）を理由に「ヒーロー 1 箇所・ナビのアクセント」への縮退を報告している。実測で多数派なのは 白地 + 1 アクセント、フラット、大型見出し、split / 全面写真 hero、可視ナビ + ヘッダー CTA、IO 出現アニメ。国内固有は 明朝 display、英字見出し + 和文本文、縦書きは見出しのみ、数字訴求。衰退側は 汎用 AI 画像、スクロールジャック、ストック写真 hero、ニューモーフィズム、全面 3D / glass、均等 12 カラム。詳細は `results/visual/trends-external.md`。

## 7. 公開安全

サイト名・URL・タイトル・スクリーンショットは含めない。`sites-index.json` は id とパターン・国・ページ種別・抽出元種別のみ。表現タグの `notable` はサイト名を含めない指示でコーディングし、統合層リポジトリの `check-public-safety.sh --staged` を通した。フォント名は公開フォントの allowlist のみ残し、サイト固有フォント・アイコンフォント・generator meta は除いた。旧テーマ以外の参照 2 テーマは テーマA / テーマB と表記。

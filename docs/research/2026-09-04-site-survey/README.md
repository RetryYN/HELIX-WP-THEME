- 見出し: 記事 h1 22 / 28、h2 20 / 23、h3 18 / 20.8。トップの h1 は国内でロゴ・サイト名を h1 にする例が多く中央値 16（海外 32）。
- 余白: 記事の h2 上 40、段落間 16。セクション padding-top トップ 45 / 70、記事 28 / 34。
- 部品: ボタン高 46 / 48、文字 14 / 16、radius 中央値 6 / 8（pill は q3 側）。カード radius 5。画像 radius 0 が多数。
- ヘッダー: SP 64–67（q1 56）、PC 90。固定ヘッダー 76%、ハンバーガー 48%（記事 52%）、下部固定 28%（記事 45%）、目次は記事 53%、パンくず記事 57%。

## 5. 外部トレンドとの突き合わせ

記事 23 出典が「既定」と書く bento（実測 2%）、glass（3%）、3D（8%）、kinetic type、marquee（2%）は実サイトでは 1 桁 %。海外の実務検証記事も性能（CWV・FPS・JS 重量）を理由に「ヒーロー 1 箇所・ナビのアクセント」への縮退を報告している。実測で多数派なのは 白地 + 1 アクセント、フラット、大型見出し、split / 全面写真 hero、可視ナビ + ヘッダー CTA、IO 出現アニメ。国内固有は 明朝 display、英字見出し + 和文本文、縦書きは見出しのみ、数字訴求。衰退側は 汎用 AI 画像、スクロールジャック、ストック写真 hero、ニューモーフィズム、全面 3D / glass、均等 12 カラム。詳細は `results/visual/trends-external.md`。

## 7. 公開安全

サイト名・URL・タイトル・スクリーンショットは含めない。`sites-index.json` は id とパターン・国・ページ種別・抽出元種別のみ。表現タグの `notable` はサイト名を含めない指示でコーディングし、統合層リポジトリの `check-public-safety.sh --staged` を通した。フォント名は公開フォントの allowlist のみ残し、サイト固有フォント・アイコンフォント・generator meta は除いた。旧テーマ以外の参照 2 テーマは テーマA / テーマB と表記。

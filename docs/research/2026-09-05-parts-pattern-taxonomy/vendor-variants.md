# vendor-variants — テーマA / テーマB の公開ページで実際に見えたパーツ variant 一覧

- 入力: `vendor/` の full-page スクリーンショット 49 ページ × PC/SP（98 jpg、capture 0 errors）。
- 読み方: PC 版を 1000px スライス（`vendor-slices/<file>--s00..`）にして全 slice を目視。SP は `vendor-crops/` の hero/mid/foot のみ抜き取り確認。
- 「見えた数」は**画面上に実物が描画されていた variant 数**。テキストで「N 種類」と書かれているだけで実物が無いものは `(記述: N)` と別記する。
- 固有名は書かない（テーマA / テーマB のみ）。ファイル参照は `vendor/` のベース名。
- 制約: 遅延読み込み画像は白/単色のまま撮れている箇所がある（`ta-feature` の s13–s24、テーマB のフッター全面、`ta-demo-4` の Pick up カード 2 枚など）。それらは「未描画」と記す。

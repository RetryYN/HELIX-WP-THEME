## 4. 実施内容

1. `wp core check-update` で更新候補を確認。
2. DBを `wp db export` でバックアップ。
3. `wp_core` Docker volume を tar でバックアップ。
4. `wp core update --version=6.9.4` を実行。
5. `wp core update-db` を実行。
6. `permalink_structure` を `/%postname%/` に修正。
7. rewrite rules を flush。
8. Akismet を `5.7` に更新。
9. Docker Compose の WordPress/PHP/WP-CLI image を更新。
10. HTTP、REST、checksums、DB、更新候補を検証。

## 6. 残課題

| 課題 | 内容 | 優先度 |
|---|---|---|
| JIN:R PHP warning | JIN:R `1.4.6` は PHP 8.3 / WP-CLI上でも customizer UI の null array offset warning が出る。画面表示は `WP_DEBUG_DISPLAY=false` のため抑制されるが、ログ品質と将来互換性の課題。 | High |
| Apache ServerName warning | Apacheログに `Could not reliably determine the server's fully qualified domain name` が出る。動作影響は小さいが、運用ログを綺麗にするならServerName設定を追加する。 | Low |

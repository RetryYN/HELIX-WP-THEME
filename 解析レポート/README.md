参照WPテーマを、新規テーマ開発に取り込むべき設計要素として分解する。コード・画像・固有デザインのコピーではなく、機能カテゴリ、設計思想、JSON操作化できる契約、個人/法人パッケージへの振り分けを抽出する。

## 判断方針

| 判断 | 方針 |
|---|---|
| 取り込む | 新テーマの価値に直結し、独自実装できる設計パターン |
| 再設計する | 方向性は有効だが、セキュリティ・保守性・AI操作性のために作り直すもの |
| 見送る | 新テーマの差別化に寄与しない、または重すぎるもの |

# パッケージ分割設計

## 分割方針

新テーマは「共通Core + 個人アフィリエイト + 法人LP」の3層にする。

| 層 | 目的 |
|---|---|
| 共通Core | WPテーマとしての基盤、共通ブロック、SEO、パフォーマンス、JSON操作 |
| 個人アフィリエイト | 収益記事、比較、ランキング、広告、レビュー、クリック計測 |
| 法人LP | 製品訴求、LPセクション、CTA、導入事例、資料DL、ブランド統制 |

## 共通Core

| 機能 | 優先 | 内容 |
|---|---|---|
| Theme Kernel | P0 | 起動、autoload、設定読み込み |
| Design Tokens | P0 | 色、余白、タイポ、角丸、影をJSON管理 |
| Template Parts | P0 | header/footer/single/archive/lpを部品化 |
| Core Blocks | P0 | FAQ、Step、Button、Accordion、Post List、Link List |
| SEO Base | P0 | title、breadcrumb、Article、FAQ |
| Asset Loader | P0 | 条件付きCSS/JS読み込み |
| Agent Actions | P0 | AI操作をJSON契約で制限 |
| Settings Export | P1 | 設定のJSON出力 |

## 個人パッケージ: アフィリエイト特化

### 中核機能

| 機能 | 優先 | 内容 |
|---|---|---|
| Review Block | P0 | 評価、メリット、デメリット、総評 |
| Ranking Block | P0 | 商品ランキング、順位、CTA |
| Comparison Table | P0 | 複数商品の比較、絞り込み前提の属性 |
| Product Card | P0 | 商品名、画像、価格、評価、CTA |
| Affiliate CTA | P0 | ボタン、リンク、rel/sponsored設定 |
| Ad Tag Manager | P0 | 広告タグ、ASPリンク、計測ID管理 |
| Blog Card | P0 | 内部/外部リンクカード |
| Related Post | P0 | 収益記事への回遊 |
| Click Tracking | P1 | CTA/広告クリック計測 |
| Disclosure | P1 | PR表記、広告表記の自動表示 |
| Profile/SNS | P1 | 個人ブランディング |

### 記事テンプレート

| テンプレート | 用途 |
|---|---|
| 商標レビュー | 商品名検索からCVを狙う |
| 比較記事 | 複数商品を比較して誘導 |
| ランキング記事 | 収益商品を順位付きで提示 |
| HowTo記事 | Step/FAQで検索流入を狙う |
| まとめ記事 | Post List/Blog Cardで回遊させる |

### 個人向けで避けるもの

| 避けるもの | 理由 |
|---|---|
| 大規模承認ワークフロー | 個人利用では重い |
| 複雑な権限管理 | 管理コストが高い |
| LP専用の大量設定 | アフィリエイト記事作成の速度を落とす |
| 法人向けブランド統制 | 価値が薄い |

## 法人パッケージ: 製品宣伝/LP強化

### 中核機能

| 機能 | 優先 | 内容 |
|---|---|---|
| LP Section Builder | P0 | Hero、Problem、Solution、Feature、Benefit、CTA |
| Brand Tokens | P0 | ブランド色、ロゴ、フォント、余白、ボタン |
| Product Card | P0 | 製品/サービスの概要カード |
| Feature Grid | P0 | 機能訴求 |
| Case Study | P0 | 導入事例、実績、業種 |
| Pricing Section | P0 | 料金、プラン、問い合わせ導線 |
| CTA Manager | P0 | 問い合わせ、資料DL、デモ申込 |
| Reusable Parts | P0 | 共通CTA、共通FAQ、共通セクション |
| Lead Tracking | P1 | CTA、資料DL、外部フォーム遷移 |
| Organization/Product Schema | P1 | 法人SEOと製品SEO |
| Settings Export/Import | P1 | 制作会社/複数サイト展開に有効 |
| Role Permissions | P1 | 管理者、編集者、承認者 |
| Audit Log | P2 | 設定変更の追跡 |

### LPセクション標準

| セクション | 目的 |
|---|---|
| Hero | 製品価値、メインCTA、ファーストビュー |
| Problem | 顧客課題を明確化 |
| Solution | 製品が解決すること |
| Feature | 機能一覧 |
| Benefit | 導入効果 |
| Use Case | 業種/用途別の見せ方 |
| Case Study | 導入実績 |
| Pricing | 価格/プラン |
| FAQ | よくある質問 |
| Final CTA | 問い合わせ/資料DL/デモ申込 |

### 法人向けで避けるもの

| 避けるもの | 理由 |
|---|---|
| アフィリエイト前提のランキングUI | 法人製品の信頼性と合わない |
| 広告タグ中心UI | 製品宣伝より広告運用に寄りすぎる |
| レビュー星評価の多用 | B2B製品では安っぽく見える場合がある |
| 個人プロフィール中心設計 | 企業サイトでは優先度が低い |

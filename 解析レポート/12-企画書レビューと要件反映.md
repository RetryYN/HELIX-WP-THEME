# 12. 企画書レビューと要件反映

## レビュー結論

`docs/planning/L0-planning.md` は、AGENT NEOの方向性、SKU、Automation SEO連携、販売ファネルを十分に表現している。一方で、レビュー時点では `docs/requirements/L1-requirements.md` と `docs/design/L2-design.md` がテンプレート状態で、L0の意思決定が要件・設計に反映されていなかった。

本実装でL1/L2をドラフト化し、G0.5企画突合ゲートは `fail` から `passed_with_draft` に更新する。正式凍結にはPOレビューが必要。

## L0企画書の強い点

| 観点 | 評価 |
|---|---|
| ビジョン | AIエージェントを第一級ユーザーにする方向が明確 |
| 価格 | 個人 `¥19,800`、法人 `¥98,000`、無料移行、S1の階層がある |
| 差別化 | REST/MCP/WP CLI/JSON契約により既存テーマと違いが出る |
| 連携 | Automation SEOとseo-tool-connectorの既存資産を活かす方針 |
| 販売導線 | 無料プラグインからテーマ/S1へ誘導するファネルがある |

## 修正すべき論点

| 論点 | 状態 | 対応 |
|---|---|---|
| L1/L2未反映 | テンプレート状態 | 要件ID、機能ID、受入条件、設計概要を追加 |
| 法人版の価格根拠 | 高額テーマに見える | LP運用基盤、計測、Automation SEO連携として説明 |
| Automation SEO費用 | 価格表に混ざる恐れ | 別課金推奨で固定 |
| ライセンス | 参照テーマ解析があるため注意 | コード/画像/CSS/固有文言のコピー禁止を明記 |
| 移行プラグイン | 無料/軽課金が未決 | 初期は無料、AI再構築はS1誘導を推奨 |

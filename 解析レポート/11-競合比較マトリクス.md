# 11. 競合比較マトリクス

## 比較方針

国内主要テーマを、価格、売り方、機能、AGENT NEOで取り込むべき抽象、上回るべきポイントで比較する。コードや素材は流用せず、設計上の勝ち筋だけを抽出する。

## 競合比較

| 競合 | 価格/課金 | 強い訴求 | 取り込む抽象 | AGENT NEOで上回る点 |
|---|---|---|---|---|
| ThemeB | `¥17,600` 買い切り | シンプル美、機能性、GPL100%、複数サイト | 薄いbootstrap、block.json中心、条件付きアセット、設定/性能の整理 | JSON操作、MCP、Automation SEO、CTA/A-B/section計測 |
| テーマA | `¥19,800` 買い切り | 初心者でも美しいブログ、デザインプリセット、BlogCamp | 1クリックデザイン、エディター体験、コミュニティ価値 | AIがプリセット適用、SEO記事生成、収益ブロックを自動構築 |
| テーマC6 | `¥14,800` 買い切り | カスタマイズ性、収益化、CTR計測 | 収益化導線、広告タグ管理、クリック計測 | section_id/cta_id/variant_idで計測を標準契約化 |
| テーマC PACK3 | `¥39,800` 買い切り | EX機能、タグ管理、ABテスト | 上位版で計測/改善を売るモデル | 法人版とAutomation SEO別課金でAI改善まで拡張 |

| 機能カテゴリ | 競合の強み | AGENT NEOの実装方針 |

## 法人版の競争相手

法人版の競争相手は「WordPressテーマ」だけではない。比較される相手は以下。

| 比較対象 | 相手の価値 | AGENT NEOの勝ち筋 |
|---|---|---|
| 制作会社のLP制作 | 個別デザイン、運用代行 | 初期構築S1 + その後AIで改善できる |
| Elementor/ページビルダー | ノーコード編集 | JSON契約でAIが壊さず操作できる |
| Headless WP | 柔軟な開発 | WP管理体験を維持し、移行コストを下げる |
| MA/SaaS | 計測/改善 | WPテーマ層からsection/CTA単位で計測する |

| SKU | NG訴求 | 採用訴求 |

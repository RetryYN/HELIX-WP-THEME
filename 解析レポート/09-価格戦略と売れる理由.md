# 09. 価格戦略と売れる理由

## 結論

AGENT NEO の価格は、個人版 `¥19,800`、法人版 `¥98,000`、移行プラグイン無料、Automation SEO は別課金で整理する。個人版は国内有料テーマの相場内に置き、法人版は単なるテーマではなく「AI運用できる法人LP基盤」として売る。

## 売れている理由の分解

| 理由 | 競合での出方 | AGENT NEOでの上位化 |
|---|---|---|
| 買い切り安心感 | SWELL/JIN:R/AFFINGERが強い | テーマ本体は買い切りを維持し、AI原価は別課金に分離 |
| 複数サイト利用 | SWELL/JIN:R/AFFINGERが訴求 | 個人所有サイト複数利用を基本に、法人は組織単位ライセンスへ拡張 |
| すぐ見た目が整う | JIN:Rのデモ/プリセット、SWELLのシンプル美 | design-tokens とプリセットをAIがJSONで適用できるようにする |
| 執筆しやすい | Gutenbergブロック、装飾、FAQ、比較表 | Automation SEOの記事生成からブロック投入まで接続 |
| 収益化しやすい | AFFINGERのタグ管理/ABテスト、Cocoonの広告/ランキング | affiliate_cta、cta_id、variant_id、section_idを標準契約化 |
| 速度/SEO | SWELL/JIN:R/Cocoonが訴求 | 条件付きアセット、JSON-LD、計測軽量化を初期要件にする |
| 情報量とサポート | JIN:Rのコミュニティ、SWELL/Cocoonのマニュアル/フォーラム | docs、MCP操作ガイド、AI操作レシピを製品価値に含める |

## 法人版 `¥98,000` の正当化条件

法人版を高額テーマとして売ると弱い。以下を満たして「運用基盤」として売る必要がある。

| 必須価値 | 内容 |
|---|---|
| LPセクションビルダー | Hero、Feature、Benefit、Use Case、Pricing、FAQ、CTAをJSONで生成/更新 |
| 計測標準装備 | section_id、cta_id、variant_id、lead_event_idを一貫管理 |
| A/Bテスト | CTA、見出し、価格訴求、資料DL導線の比較 |
| ブランド管理 | brand_tokensで色、余白、フォント、ロゴ、角丸を統制 |
| Automation SEO連携 | 記事/LP/SEOメタ/構造化データの再生成と投入 |
| 初回構築導線 | 導入時の不安をS1で吸収し、法人購買の稟議理由を作る |

## 販売ファネル

1. 無料移行プラグインで接点を取る。
2. 既存サイト診断で「機械変換で十分」か「AI再構築が必要」かを提示する。
3. 個人は `¥19,800` テーマ購入へ誘導する。
4. 法人は `¥98,000` 法人版 + S1 + Automation SEO別課金へ誘導する。
5. 計測データを継続改善の根拠にし、アドオン/保守/記事生成へつなげる。

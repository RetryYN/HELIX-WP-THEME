# 計測と連携性分析

## 目的

参照テーマにあるPV、ボタン、広告の計測発想を、新テーマの個人アフィリエイト/法人LP向けに再設計する。あわせて、外部サービス、REST API、AIエージェント、WordPress標準機能との連携性を整理する。

## 参照テーマの計測系から得られる示唆

| 観測 | 価値 | 再設計ポイント |
|---|---|---|
| PV計測API | 人気記事や表示回数に使える | bot対策、キャッシュ環境対応、rate limitが必要 |
| ボタン計測 | CTAのクリック/表示計測に使える | CTA IDとイベント種別を統一する |
| 広告計測 | アフィリエイト広告のimp/clickに有用 | 個人パッケージ専用に寄せる |
| リセットAPI | 管理者が計測値を初期化できる | 権限、nonce、監査ログ必須 |
| フロントJS変数 | REST URLやnonceを渡す | `window.AgentNeo` のような名前空間で統一 |

## 計測イベント設計

| event | 個人 | 法人 | 内容 |
|---|---:|---:|---|
| `page_view` | yes | yes | 記事/LP表示 |
| `cta_impression` | yes | yes | CTAが画面内に表示された |
| `cta_click` | yes | yes | CTAクリック |
| `affiliate_click` | yes | no | ASP/広告リンククリック |
| `ad_impression` | yes | no | 広告表示 |
| `ad_click` | yes | no | 広告クリック |
| `lead_click` | no | yes | 問い合わせ/資料DL/デモ申込クリック |
| `external_form_click` | no | yes | HubSpot/フォーム等への遷移 |
| `document_download_click` | no | yes | PDF/資料DL |

## REST API契約案

| API | Method | 認可 | 用途 |
|---|---|---|---|
| `/wp-json/agent-neo/v1/events` | POST | nonce + rate limit | フロントイベント送信 |
| `/wp-json/agent-neo/v1/events/summary` | GET | `manage_options` | 管理画面集計 |
| `/wp-json/agent-neo/v1/events/reset` | POST | `manage_options` + nonce | 計測リセット |
| `/wp-json/agent-neo/v1/settings` | GET | `edit_posts` | エディター/管理画面設定取得 |
| `/wp-json/agent-neo/v1/settings` | POST | `manage_options` + nonce | 設定更新 |
| `/wp-json/agent-neo/v1/agent/actions/dry-run` | POST | `manage_options` + nonce | AI操作の事前検証 |
| `/wp-json/agent-neo/v1/agent/actions/apply` | POST | `manage_options` + nonce | AI操作の適用 |

## 計測保存方式

| 方式 | 長所 | 短所 | 推奨 |
|---|---|---|---|
| post meta加算 | 実装が簡単 | 高頻度更新に弱い、集計が粗い | 初期/小規模 |
| custom table | 高頻度・集計に強い | migrationが必要 | 法人/本格計測 |
| 外部Analytics送信 | GA4等と統合しやすい | 外部依存、同意管理が必要 | オプション |
| server log集計 | bot除外しやすい | 実装/運用が重い | 後回し |

## 個人アフィリエイト向け計測

| 計測対象 | 目的 | 実装方針 |
|---|---|---|
| 商品カード表示 | imp計測 | IntersectionObserverで表示判定 |
| アフィリエイトCTAクリック | CV導線分析 | `affiliate_click` を送信 |
| ランキング内CTA | 順位別クリック率 | componentIdにrankを含める |
| 比較表CTA | 商品別/列別クリック | tableId + productId |
| 広告タグ | ASP/広告枠別集計 | adId、network、placement |

## 法人LP向け計測

| 計測対象 | 目的 | 実装方針 |
|---|---|---|
| Hero CTA | LP主導線の効果測定 | `lead_click` |
| 資料DL | リード獲得 | `document_download_click` |
| 外部フォーム遷移 | HubSpot等との連携 | `external_form_click` |
| 価格セクションCTA | プラン検討の強度 | pricing plan IDを含める |
| 導入事例CTA | 事例からのCV | caseStudyIdを含める |

## 外部連携性

| 連携先 | 個人 | 法人 | 設計方針 |
|---|---:|---:|---|
| GA4 | yes | yes | 任意。イベント名をGA4変換できるadapterを用意 |
| Google Tag Manager | yes | yes | dataLayer push adapter |
| ASPリンク | yes | no | 個人専用。URL/rel/計測IDを管理 |
| HubSpot | no | yes | 外部フォーム遷移/埋め込み/CTA計測 |
| Salesforce/Pardot | no | yes | 初期は外部URL計測、API直連携は後回し |
| Mailchimp等 | limited | yes | フォーム埋め込み/外部URL連携 |
| Search Console | yes | yes | 直接APIより、構造化データ/サイトマップ品質を優先 |
| AIエージェント | yes | yes | JSON action経由で設定/ブロック/LPを生成 |

## 連携アダプター設計

```json
{
  "adapter": "gtm",
  "enabled": true,
  "maps": {
    "cta_click": "agent_neo_cta_click",
    "affiliate_click": "agent_neo_affiliate_click",
    "lead_click": "agent_neo_lead_click"
  },
  "transport": "dataLayer"
}
```

## AIエージェント連携性

| 連携点 | 内容 |
|---|---|
| `package.matrix.json` | 個人/法人の有効機能を判断 |
| `block-registry.json` | 生成可能なブロックと属性を判断 |
| `layout-registry.json` | LP/記事テンプレート構成を判断 |
| `agent-actions.schema.json` | 実行可能な操作を制限 |
| `analysis-summary.json` | 参照解析結果を再利用 |
| dryRun API | 変更前に差分と影響範囲を返す |

## セキュリティ要件

| リスク | 対策 |
|---|---|
| 公開RESTの濫用 | nonce、rate limit、bot判定、短時間重複排除 |
| 外部URL悪用 | URL allowlist、protocol制限、rel属性自動付与 |
| 管理設定改ざん | `manage_options`、nonce、監査ログ |
| XSS | CTAラベル/HTMLはsanitize、HTML許可範囲を限定 |
| 個人情報 | 計測イベントにメール、氏名、電話番号を入れない |

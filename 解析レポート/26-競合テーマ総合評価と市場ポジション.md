# 競合テーマ総合評価と市場ポジション

## 結論

AGENT NEOが目指すべき市場ポジションは、既存テーマの単純な上位互換ではなく、**AI運用型WPテーマ基盤**である。

個人版は「ThemeB/テーマAの使いやすさ + テーマCの収益化 + AI記事投入/計測/LLMO」を狙う。法人版は「テーマEの法人安心感 + LP改善/A/B/計測 + AI運用」を狙う。価格競争、デザイン競争、SEO保証競争に入ると勝ち筋が薄い。

## 評価軸

| 評価軸 | 配点 | 見るポイント |
|---|---:|---|
| 市場適合・販売力 | 15 | 価格納得感、導入しやすさ、販売メッセージ、利用者層の広さ |
| デザイン/UX | 15 | 初心者でも見栄えを作れるか、設定UI、デモ/プリセット、認知負荷 |
| SEO/構造化データ | 15 | SEOメタ、canonical/noindex、JSON-LD、内部構造、運用しやすさ |
| 速度/Core Web Vitals | 15 | 条件付きアセット、不要JS抑制、画像/フォント、表示安定性 |
| 収益化/LP/CV | 15 | 広告、CTA、ランキング、比較、LP、A/B、計測 |
| 運用/更新/サポート | 10 | マニュアル、フォーラム、更新、互換性、法人導入の安心感 |
| AI運用/将来性 | 15 | JSON操作、安定ID、API、LLMO、AIクローラ、機械可読性 |

点数は「一般ユーザー満足度」ではなく、AGENT NEOの設計参考・競争相手としての総合評価である。

## ThemeB: 88点

### いいポイント

| 観点 | 評価 |
|---|---|
| 市場性 | `¥17,600`、買い切り、GPL100%、複数サイト利用可という価格/ライセンスの安心感が強い |
| UX | 管理画面、ブロック、設定、マニュアル、フォーラムの全体完成度が高い |
| 速度 | 条件付きアセット、ブロックCSS、遅延読み込み、不要機能抑制など速度設計の参考価値が高い |
| 汎用性 | ブログ、メディア、簡易LPまで広く扱える |
| 信頼 | 国産有料テーマとして「迷ったらThemeB」の位置を取っている |

### よくないポイント

| 観点 | 課題 |
|---|---|
| AI運用 | AIが安全に編集するためのJSON操作契約、section_id、dryRun、MCP、WP-CLI契約は標準価値になっていない |
| 法人LP | LP専用の計測/A-B/改善ワークフローはAGENT NEOが狙う法人基盤ほど強くない |
| SEO拡張 | SEOは十分強いが、LLMO、evidence graph、AI crawler policy、AI経由CV計測までは製品化されていない |
| 差別化余地 | 完成度が高いぶん、単なる後追いデザイン/速度では勝てない |

### 取り込むべき設計

- 速度設計、設定UIの整理、フォーラム/マニュアル導線、買い切り安心感。
- ただしコード、CSS、画像、固有文言は流用せず、アーキテクチャ原則だけ抽象化する。

## テーマA: 82点

### いいポイント

| 観点 | 評価 |
|---|---|
| デザイン | 「美しさ」と「使いやすさ」の訴求が明確。初心者でも見栄えを作れるプリセット思想が強い |
| SEO | SEO、構造化データ、OGP、canonical/noindexをテーマUXとして扱う発想がAGENT NEOのSEO Coreに近い |
| 販売導線 | `¥19,800`、複数サイト利用、BlogCamp特典により価格納得感を作っている |
| ブロガー心理 | 「ブログで稼ぐ」「迷わず作れる」「執筆に集中できる」という訴求が強い |
| 企画性 | テーマA旧版からテーマAへ作り直したストーリーが、品質投資の納得材料になっている |

### よくないポイント

| 観点 | 課題 |
|---|---|
| 速度 | 実コード観測ではグローバルCSSやjQuery依存の影響があり、速度基盤はThemeB型を優先すべき |
| AI運用 | SEO設定は人間GUI前提で、AIが安全に一括変更・差分レビュー・rollbackする契約ではない |
| 法人運用 | 承認、監査ログ、SLO、プラグイン衝突、外部API障害時fallbackなど法人運用基盤は薄い |
| デザイン偏り | プリセットが強い反面、サイトが「テーマAっぽく」見えやすいリスクがある |

### 取り込むべき設計

- SEO統合UX、デモ/プリセットによる初期完成度、ブロガー向けの心理的訴求。
- AGENT NEOではSEOを `seo-profile.json`、`entity-graph.schema.json`、`content-origin.schema.json` に分解してAI操作可能にする。

## テーマC6 / ACTION PACK: 80点

### いいポイント

| 観点 | 評価 |
|---|---|
| 収益化 | アフィリエイト、広告、ランキング、コード管理、上位PACKによる収益化訴求が強い |
| 価格帯 | 通常版 `¥14,800`、上位PACK `¥39,800` で、段階課金と高ARPUの設計ができている |
| 計測 | クリック計測、タグ管理、A/Bテストを上位価値として売れる構造がある |
| 顧客像 | 「稼ぎたい人」に刺さるメッセージが明確 |

### よくないポイント

| 観点 | 課題 |

| AI運用 | 機能の粒度が人間操作前提で、AIが目的から安全に組み立てる設計ではない |
| 法人展開 | 代理店/法人LP運用基盤として売るには、権限、監査、契約、SLOの補強が必要 |

### 取り込むべき設計

- 上位PACKの価格戦略、アフィリエイト収益化ブロック、CTA/タグ/A-B/CTR計測の価値訴求。
- AGENT NEOでは「設定項目の多さ」ではなく、`conversion-intent.schema.json` と `ui-risk.schema.json` で目的駆動に再設計する。

## 勝つために避けるべきこと

| NG | 理由 |
|---|---|
| 「ThemeBより美しいテーマ」として売る | ThemeB/テーマAの強い土俵で比較され、差別化が弱くなる |
| 「SEOに強い」とだけ売る | 既存テーマも同じことを言える。Google/AI検索時代では根拠、更新日、引用、リスク管理まで必要 |
| すべてをテーマ本体に詰める | plugin territory、保守、更新、データ移植性、wp.org申請で詰む |
| 設定項目を増やして高機能に見せる | テーマC型の複雑さを再生産し、AI操作性も人間UXも悪くなる |
| AI生成量を価値として売る | SEOスパム/品質リスクが高い。価値はAI運用の安全性、改善速度、計測、根拠管理に置く |
| 法人版を「高額テーマ」として売る | `¥98,000` はテーマ価格として高い。LP運用基盤/S1/計測改善として売る必要がある |

## AGENT NEOの差別化メッセージ案

| 対象 | メッセージ |
|---|---|
| 個人版 | 記事生成で終わらない。比較、ランキング、CTA、PR表記、クリック計測までAIが扱える収益化テーマ |
| 法人版 | LPを作って終わらない。AIがセクション単位で改善し、CTA/A-B/LLMOまで運用する法人WP基盤 |
| 移行導線 | 既存テーマから、AIが運用できる構造へ。無料プラグインで診断し、必要ならAI再構築へ |
| 競合比較 | 既存テーマは人間が編集しやすい。AGENT NEOはAIも安全に編集できる |

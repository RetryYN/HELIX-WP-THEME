# SEO Skill Map

SEO業務を9カテゴリ・60スキルに分解した体系マップ。タスク受領時にどのスキル群を参照すべきか判断するためのインデックスとして使用する。

## 全体構造

```
SEO
├── 1. 戦略 (Strategy)
├── 2. オンページSEO (On-Page)
├── 3. テクニカルSEO (Technical)
├── 4. コンテンツSEO (Content)
├── 5. オフページSEO (Off-Page)
├── 6. 国際SEO (International)
├── 7. アナリティクス (Analytics)
├── 8. UX
├── 9. AI SEO
└── 10. 成長 (Growth)
```

---

## 1. 戦略 (Strategy)

サイト立ち上げ・リニューアル・新規事業領域参入時に最初に行う上流工程。

| スキル | 目的 | 主要アウトプット |
|---|---|---|
| キーワードリサーチ | 獲得対象キーワードの網羅的洗い出し | キーワードリスト（検索ボリューム・難易度付き） |
| 検索意図 | クエリ背後のユーザー意図分類 | Informational/Navigational/Commercial/Transactional分類表 |
| 競合分析 | 上位サイトの構造・コンテンツ分析 | 競合マッピング、ギャップ分析レポート |
| キーワードクラスタリング | 意味的に近いKWのグルーピング | クラスタマップ（ピラー/クラスタ構造の元） |
| SEOの成功事例 | 自社/他社のベンチマーク | ケーススタディ集 |

## 2. オンページSEO (On-Page)

個別ページ単位の最適化。ページ内要素の改善。

| スキル | 目的 |
|---|---|
| タイトル | titleタグ最適化、CTR向上 |
| メタ記述 | meta description最適化 |
| ヘッダー構造 | h1〜h6の論理階層設計 |
| URL構造 | 可読性・階層性のあるURL設計 |
| 内部リンク | リンクジュース流通・回遊性設計 |
| 画像最適化 | alt属性・ファイル名・圧縮・WebP |
| コンテンツ最適化 | 本文のKW配置・可読性・網羅性 |

## 3. テクニカルSEO (Technical)

検索エンジンのクロール・インデックスを支える技術基盤。

| スキル | 目的 |
|---|---|
| クローラビリティ | robots.txt、クロールバジェット管理 |
| インデックス化 | noindex制御、重複排除 |
| サイト速度 | Core Web Vitals、LCP/FID/CLS改善 |
| スキーママークアップ | 構造化データ（JSON-LD）実装 |
| 正規URLタグ | canonical設定で重複コンテンツ対応 |
| XMLサイトマップ | sitemap.xml生成・送信 |

## 4. コンテンツSEO (Content)

検索獲得の主戦場。コンテンツ資産の設計と量産。

| スキル | 目的 |
|---|---|
| ブログコンテンツ | 単発記事の企画・執筆 |
| ピラーページ | テーマの中核となる包括ページ |
| トピッククラスタ | ピラー＋関連クラスタ記事群の連携設計 |
| ツールコンテンツ | 計算機・診断・テンプレ等のインタラクティブ資産 |
| エバーグリーンコンテンツ | 鮮度劣化しにくい長寿命コンテンツ |
| プログラマチックSEO | DB×テンプレで大量ページ自動生成 |
| コンテンツ刷新 | 既存記事のリライト・再公開 |

## 5. オフページSEO (Off-Page)

サイト外からの権威性・被リンク獲得。

| スキル | 目的 |
|---|---|
| リンクビルディング | 被リンク獲得施策全般 |
| ゲスト投稿 | 他サイトへの寄稿によるリンク獲得 |
| デジタルPR | プレスリリース・メディア露出 |
| ブランド言及 | サイテーション獲得（リンク無しメンションも含む） |
| アウトリーチ | リンク依頼メール・関係構築 |

## 6. 国際SEO (International)

多言語・多地域展開時の最適化。

| スキル | 目的 |
|---|---|
| Hreflang | 言語・地域別ページのマッピング |
| 多言語対応 | 翻訳品質・URL構造設計 |
| ジオターゲティング | 国・地域ごとのターゲット設定 |
| ローカライズ | 文化・通貨・表記の現地化 |

## 7. アナリティクス (Analytics)

施策の計測・効果検証。

| スキル | 目的 |
|---|---|
| Google Analytics | GA4でのトラフィック・行動分析 |
| Search Console | 検索パフォーマンス・カバレッジ監視 |
| 順位追跡 | KWごとの順位モニタリング |
| トラフィック分析 | 流入チャネル・ページ別分析 |
| KPI追跡 | SEO KGI/KPIダッシュボード設計 |

## 8. UX

検索体験を超えたユーザー体験全般。間接的にSEOに寄与。

| スキル | 目的 |
|---|---|
| ページ速度UX | 体感速度・ジャンプ防止 |
| モバイル最適化 | レスポンシブ・タップ領域・モバイルファースト |
| UXデザイン | 情報設計・導線設計 |
| A/Bテスト | 変更施策の定量検証 |
| コンバージョンファネル | 流入→CVのボトルネック特定 |

## 9. AI SEO

LLM時代の検索最適化（GEO/LLMO/AEOを含む）。

| スキル | 目的 |
|---|---|
| コンテンツ最適化 | AI検索エンジン向けコンテンツ設計 |
| NLP最適化 | エンティティ・セマンティック最適化 |
| 生成SEO | AI生成コンテンツの品質管理・差別化 |
| SERP機能 | AI Overview、強調スニペット、FAQ等の獲得 |
| LLM可視性 | ChatGPT/Perplexity/Gemini等での被引用最適化 |

## 10. 成長 (Growth)

中長期での資産積み上げと拡張。

| スキル | 目的 |
|---|---|
| トピックオーソリティ | 特定領域での専門性・権威性確立 |
| コンテンツスケーリング | 量産体制・品質維持の仕組み |
| リンク獲得 | 継続的な被リンク獲得プロセス |
| SEO実験 | 仮説→実装→検証のサイクル |

## 使い方

タスクが来たら次の順で判断する。

1. **どのカテゴリか特定**: タスクを上記9カテゴリのいずれかに分類
2. **該当スキルを抽出**: カテゴリ内の個別スキルを1〜複数選択
3. **依存関係を確認**: 戦略 → オンページ/テクニカル/コンテンツ → オフページ/分析 → 改善の順で組む
4. **KPIにひもづけ**: アナリティクス・成長カテゴリと接続して効果測定設計

### よくあるタスクパターン

- **新規サイト立ち上げ**: 戦略 → テクニカル → コンテンツ → オンページ → 分析
- **既存サイト改善**: 分析 → ボトルネック特定 → 該当カテゴリ施策
- **AI検索対応**: AI SEO + コンテンツSEO + スキーママークアップ
- **多言語展開**: 国際SEO + テクニカル（hreflang/canonical）+ コンテンツ刷新

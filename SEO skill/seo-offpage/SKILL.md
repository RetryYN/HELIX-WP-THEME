# seo-offpage

## Purpose

外部評価を、スパムではなくブランド、実績、一次情報、自然な引用で増やす。

## Inputs

- 既存被リンク、ブランド言及、導入事例、プレス素材、調査データ。
- 競合の被リンク傾向、掲載メディア、提携先、業界団体。

## Process

1. 被リンク候補をメディア、業界団体、顧客事例、パートナー、調査引用に分類する。
2. リンク目的だけの低品質施策を除外する。
3. 自社が出せる一次情報、調査、テンプレート、ツールを洗い出す。
4. Outreach文面、LP、メディアキット、引用可能データを設計する。
5. ブランド言及とリンクの増加をKPI化する。

## Outputs

- `offPageOpportunityMap`
- `digitalPrPlan`
- `outreachList`
- `brandMentionTracker`

## AGENT NEO Rules

- 有料リンク、隠しリンク、自動コメント、低品質ディレクトリ登録は採用しない。
- 法人版は導入事例、調査レポート、ホワイトペーパーをリンク獲得資産にする。
- 個人版は比較表、検証レビュー、テンプレート、診断ツールを引用獲得資産にする。
